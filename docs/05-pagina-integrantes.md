# Página dos integrantes (Parte 7)

No painel do WordPress: **Páginas → Adicionar nova**, título *"Integrantes do
Grupo 1"*. Use um bloco **HTML personalizado** e cole o código abaixo (troque os
nomes). Depois, em **Configurações → Leitura → Página inicial**, escolha essa
página como página inicial.

```html
<h1>Integrantes do Grupo 1</h1>
<p>Disciplina: CIC1001 – Redes de Computadores II</p>
<ul>
  <li>Integrante 1 – <em>matrícula</em></li>
  <li>Integrante 2 – <em>matrícula</em></li>
  <li>Integrante 3 – <em>matrícula</em></li>
  <li>Integrante 4 – <em>matrícula</em></li>
  <li>Integrante 5 – <em>matrícula</em></li>
</ul>
<p>Servidor LAMP publicado em <strong>http://www.grupo1.redes2.internal</strong>.</p>
```

> Também é possível criar a página diretamente pelo banco ou usar o editor
> visual (blocos Lista + Título) — o resultado é equivalente.
